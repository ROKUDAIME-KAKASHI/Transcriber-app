<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebView JS -> DocumentExport | Remote web code passes arbitrary HTML and a file name to native code |
| App cache -> other apps | Exported files leave the app through FileProvider grants |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Tampering | DocumentExport print WebView | mitigate | `setJavaScriptEnabled(false)`, `setAllowFileAccess(false)`, `setAllowContentAccess(false)`, `loadDataWithBaseURL(null, ...)`; JS side escapes every text node (plan 01-03) |
| T-01-05 | Tampering | `fileName` -> File path | mitigate | Java sanitizes to `[A-Za-z0-9._-]`, forces `.pdf`, fixed `getCacheDir()/exports` directory |
| T-01-06 | Denial of service | htmlToPdf | mitigate | BUSY guard, 90 s timeout, single settle guard, WebView destroyed in cleanup and handleOnDestroy |
| T-01-07 | Information disclosure | Logs | mitigate | Never log HTML/meeting text; only error codes |
| T-01-08 | Information disclosure | Build secrets | mitigate | Debug build only; keystore.properties and .env* never read or printed |
| T-01-09 | Spoofing | Wrong server URL baked into APK | mitigate | `CAP_SERVER_URL` always set on sync; grep check that capacitor.config.json has the Vercel URL |
</threat_model>
