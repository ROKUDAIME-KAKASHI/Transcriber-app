export type ExportKind = "txt" | "docx" | "pdf";

| Boundary | Description |
|----------|-------------|
| Meeting text (user/AI generated) -> export HTML/DOCX | Untrusted text becomes markup |
| Web code -> native Filesystem/Share/DocumentExport | Remote JS writes files and opens intents |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-10 | Tampering (HTML injection) | html.ts | mitigate | `escapeHtml` on every text node and attribute; mdast `html` nodes emitted as escaped text; links only for http/https; print WebView has JS disabled (plan 01-02) and the web iframe uses `srcdoc` with no scripts generated |
| T-01-11 | Tampering | exportFileName | mitigate | Base reduced to `[A-Za-z0-9_-]`; Java re-sanitizes; writes only under `Directory.Cache/exports` |
| T-01-12 | Information disclosure | Cache exports | mitigate | Files live in app cache only, shared via FileProvider read grant per intent, swept after 1 day by `cleanupOldExports` (plan 01-01) |
| T-01-13 | Information disclosure | Clipboard fallback | accept | Only on explicit user tap; copies text the user is already viewing |
| T-01-14 | Denial of service | Large transcripts | accept | Builders are linear; HTML built once per tap; single plugin call (RESEARCH Pitfall 11) |
</threat_model>
