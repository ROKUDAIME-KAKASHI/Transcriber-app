<interfaces>
Current server contract (from the repo, must stay compatible):
- POST /api/meetings body zod `{ title?: string(1..200), language: string(max 10, default "en"), deviceName?: string(max 60) }` -> 201 `{ meeting: { id, title } }`.
- PATCH /api/meetings/:id body `{ title?, transcript?: Part[], transcriptTail?: { from, parts: Part[] }, durationSec?, status?: "RECORDING"|"DONE" }`.
  Tail path: findFirst select transcript -> 409 `{ error, savedParts }` when from > current.length -> merged = current.slice(0, from) + parts -> 413 when > MAX_PARTS (60 000) -> updateMany -> `{ ok: true, savedParts: merged.length }`.
  Non-tail path: updateMany({ where: { id, userId }, data }) -> count ? `{ ok, savedParts: data.transcript?.length }` : 404.
  The Android RecordingService (Java) PATCHes `{ transcriptTail, durationSec, status? }` with a cookie, treats 409+savedParts as resync and any other non-2xx (incl. 404) as error. It never sends id/titleUpdatedAt/engine/speakerNames.
- Each route file defines its own `dbDown(err)` -> 503 `{ error: "The database is waking up. Try again in a few seconds." }`.
- `getUserId(): Promise<string | null>`, `unauthorized()` from `@/lib/auth`; `prisma` from `@/lib/prisma`.
- `RecordEngine` = `"moonshine" | "whisper" | "deepgram"` (src/lib/speech/deepgram.ts; confirm `Engine` there).
- `src/app/meetings/[id]/page.tsx` and `src/app/api/meetings/[id]/process/route.ts` (L166) and GET /api/meetings/:id use `findFirst({ where: { id, userId } })` with NO select. /process reads only `meeting.transcript`, `meeting.title`, `meeting.durationSec` (L173, L181) and writes `{ document, template }` via `prisma.meeting.update` (L212).

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information disclosure | POST /api/meetings with a foreign id | mitigate | 409 `{ error: "Id in use" }` only; no title/transcript of the owner returned |

| T-02-04 | Tampering | Back/forward-dated createdAt / titleUpdatedAt | mitigate | `clampClientTime`: not before 2020, not after server now + 5 min |
| T-02-05 | Tampering | Device overwriting AI document | mitigate | PatchBody has no document/template keys (zod strips them) |
| T-02-06 | Denial of service | /api/health waking Neon | mitigate | No prisma/auth import in the health route |
| T-02-07 | Availability | Deploy before schema push | mitigate | Explicit selects + `withLegacyFallback` on P2022; README deploy-order note |
