<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network -> SW precache | install-time fetches could be redirected or captive-portal HTML |
| URL -> SW redirect rule | /meetings/<id> path segment becomes a redirect target |
| build hook -> public/ | generated script served to every client at scope / |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | SW install fetches | mitigate | Install guard res.ok && !res.redirected && type basic; any failure rejects install and the old SW stays |
| T-03-02 | Tampering | /meetings/<id> redirect rule | mitigate | Target is the fixed path /meeting?id= plus an id matching the shared MEETING_ID_RE; no open redirect; parity test |
| T-03-03 | Information disclosure | SW caches | mitigate | /api/* and cross-origin never intercepted; only public static assets and user-independent shells cached; check-build asserts shells carry no session token string |
| T-03-04 | Denial of service | stale SW after deploy | mitigate | Version includes timestamp; activate prunes old shells; updateViaCache none registration (plan 03) |
| T-03-05 | Elevation | synthetic responses lose isolation | mitigate | 302 and inline fallback built with COOP/COEP headers; asserted in check-build |
| T-03-SC | Tampering | npm installs | accept | No packages are installed by this plan (supply-chain surface zero) |
</threat_model>
