| T-03-10 | Denial of service | reload loop | mitigate | sessionStorage guard + 60 s window in shouldReloadForChunkError (tested) |
| T-03-11 | Tampering | stale/dev SW serving old chunks | mitigate | production-only registration; dev unregisters and clears tr-* caches |
| T-03-SC | Tampering | npm installs | accept | No packages installed |
