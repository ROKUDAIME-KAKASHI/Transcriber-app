## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL (?id= / pathname) -> client fetch | untrusted id becomes an API path |
| static shell -> user data | shells are public/cached; data only from Dexie/API |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-12 | Tampering | MeetingLoader id from URL | mitigate | resolveMeetingId validates against MEETING_ID_RE; encodeURIComponent on the API URL; raw id never rendered |
| T-03-13 | Information disclosure | shells cached by SW | mitigate | pages contain no server-side user data (no getUserId/Prisma); check-build asserts no session token string; API still enforces auth |
| T-03-14 | Tampering | /meetings/[id] redirect | mitigate | notFound() for ids failing the regex; redirect target is a fixed path |
| T-03-SC | Tampering | npm installs | accept | No packages installed |
</threat_model>
