<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage cached {id,email} -> UI | decides what renders when the server is unreachable |
| /api/auth/session response -> gate | network response decides sign-in state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-15 | Spoofing | cached identity renders app for another person on a shared phone | accept | Cache only decides UI; every /api/* still requires the httpOnly JWT cookie; explicit sign-out clears both cache keys (documented: Dexie data kept per Phase 2 D-08) |
| T-03-16 | Spoofing | captive portal HTML parsed as session | mitigate | Probe requires res.ok and valid JSON; otherwise "unreachable" |
| T-03-17 | Tampering | token stored client-side | mitigate | Only id and email cached; no token or cookie value ever written to storage |
| T-03-18 | Repudiation/State | offline sign-out leaves cookie but clears cache | mitigate | Sign-out disabled offline; markSignedOut only when sign-out can proceed |
| T-03-19 | Denial of service | redirect loop /login <-> app | mitigate | redirect only on ok-empty (server answered); /login is outside the gate |
| T-03-SC | Tampering | npm installs | accept | No packages installed |
</threat_model>
