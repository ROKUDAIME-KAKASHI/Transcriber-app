If count > maxItems (REFINE_MAX_ITEMS 300), build micro-clusters: group indexes by `opts.live?.[i] ?? 0`, walk each group in time order and cut it into consecutive chunks of size g = ceil(count / maxItems); each micro-cluster = normalised mean + weight = size. Run average-linkage AHC on items with a full cosine-distance matrix (Float32Array k*k) and the Lance-Williams update d(k, i∪j) = (n_i d(k,i) + n_j d(k,j)) / (n_i + n_j); merge the closest pair while its distance < threshold (AHC_THRESHOLD 0.70). Then small-cluster cleanup: when there are >= 6 embedded phrases, a cluster with total weight 1 merges into its nearest cluster if similarity > 0.2. Expand item labels back to parts, fill nulls by inheritance, then renumber by first appearance.
