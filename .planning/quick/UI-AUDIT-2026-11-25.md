# UI audit 2026-11-25 (branch ui-audit-fixes)

Code-level audit of the screens changed since 963c0f6. The app's established tokens (Panel with shadow-card, radius-chip/btn/panel, glass bottom nav) were kept as-is; new screens were matched to them.

## Meeting page
| Where | Issue | Fix |
|---|---|---|
| MeetingTabBar | On mount it called scrollIntoView on the tab, which could scroll the whole page down to the tab bar | Scrolls only the tab row sideways |
| MeetingTabBar | Five tabs overflow on a phone with the scrollbar hidden and no hint | Right-edge fade while more tabs are off screen |
| MeetingTabBar | Focus ring clipped by the overflow container | Focus outline drawn inside the tab |
| MeetingTabBar / MeetingView | Tab always read "Minutes" even for a Report | `labels` prop; MeetingView passes docName |
| SummaryTab | Write summary disabled with no reason when there is no transcript | Reason line added (matches Ask) |
| SummaryTab, AskTab | Errors were bare red text, unlike the boxed error in MinutesStatus | Both use Notice (danger) |
| SummaryTab | "switched on" wording | "on" |
| AskTab | Opening the tab with saved chat scrolled the page to the bottom | Scroll follows only after a question is asked |
| AskTab | Question box fell out of view in a long chat; hidden behind bottom nav risk | Form is sticky above the floating bottom bar (bottom-0 on laptop); status, error, gate lines moved above it |
| AskTab | Offline icon shown for the "no transcript" reason | Icon only for connectivity reasons |
| AskTab | Enter submitted while a Hindi/IME word was being composed | Ignored while composing |
| AskTab | Loading line had no spinner (MinutesStatus has one) | Spinner added |
| NamingReport | `rounded-card` is not a defined radius, so the box had square corners | rounded-chip, hairline border; Copy button shrink-0 |

## Record screen
| Where | Issue | Fix |
|---|---|---|
| GuidedCall | Large primary button competed with the main record button | Always secondary |
| GuidedCall | Online-call block (label, link, button, beta toggle with long note) always expanded | Collapsed details row; opens itself for a planned call link or a share problem |
| CallGuide | No focus trap, focus not restored | Tab trap and focus returns to opener on close |
| CallGuide | SVG mock used white fill/stroke (poor contrast on dark-mode accent) | accent-foreground token |
| CallGuide | SVG text rendered about 10px | Larger mock (max 300px) and text 10.5 units, about 13px rendered; label shortened to fit |
| CallGuide | Checkbox row 32px tall | 44px |
| tabAudio copy | Straight quotes, "Share tab audio" differing from the guide, missing full stop | Matched to "Also share tab audio" wording |

## Not changed (decisions)
- Panel shadow, 10/14/22 radii and the blurred floating bottom nav are existing app-wide design, outside this pass.
- The tab bar is not sticky (the header above is tall); left as is.
- "Join call" link is 32px tall but laptop-only (hidden on coarse pointers and in the app).
- Not checked in a browser: sign-in needed for these screens.
